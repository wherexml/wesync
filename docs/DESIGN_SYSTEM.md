# GreenBubbles 原生桌面设计系统

## 方向

保留 SwiftUI / AppKit 与 macOS 14 支持。参考 ChunUI 的灰阶层次、单一品牌色、连续圆角和轻微按钮质感；不引入其 iOS 包、UIKit 呈现层或手机尺寸。实现为原创桌面样式，不复制上游源码。

参考：https://github.com/liseami/ChunUI

## 组件边界

- `HistoryDesign.swift`：语义背景、品牌绿、选中态、边框、12 pt 气泡圆角；`HistoryActionStyle` 只显式用于操作按钮，提供按压和禁用反馈。
- `HistoryChatPalette.swift`：聊天区、收发气泡和文字对比度以 `DARK_MODE.md` 为准，不在设计层重复定义。
- 实时浏览保持双栏，导入浏览保留原生分栏；搜索保留 NSSearchField 的输入法协调，分类保留系统 segmented picker，列表和菜单保留原生键盘交互。
- 欢迎页采用 28 pt 标题，实时聊天栏采用 22 pt 标题；正文及列表保留桌面密度，不套用手机三档字号。
- 轻阴影只用于按钮，不在长消息列表加入持续动画。保留橙色警告和红色错误语义。
- 图片消息保持透明背景、原有缩略图尺寸与同侧对齐；不变更分页、缓存、连接与凭据处理。
- 聊天栏右上角保留折叠图标及 32 × 32 pt 的齿轮“高级设置”按钮，直接打开连接设置，使用悬浮提示和辅助功能名称，不叠加下拉箭头。旧菜单的全局搜索、返回聊天、来源信息和忘记连接入口移除；会话筛选、聊天内搜索及搜索结果页返回按钮保留，忘记连接只在设置中操作。
- 高级设置顶部“会话显示”使用原生 Picker：联系人和群聊时间范围，五档选项，立即生效并保存；详见 `CONVERSATION_RANGE.md`。
- 会话搜索使用 32 pt 高、9 pt 圆角、轻边框的 `HistorySearchField`，保留 AppKit 原生输入法、清空按钮及实时筛选；详见 `SEARCH.md`。
- 消息搜索默认折叠为刷新左侧的 32 × 32 pt 搜索图标，点击后仅在图标左侧展开输入框，不另占常驻搜索行；回车提交，Esc 或再次点击图标收起。

## 高级设置入口验收

原生退出并重开安装版，确认无需输入密钥即恢复聊天列表；右上角应仅显示一个齿轮，无菜单箭头。点击“高级设置”应直接打开连接设置，取消后保持会话列表可用，再退出重开复验。不要点击“忘记已保存的连接”或提交新凭据。脱敏结果见 `acceptance/advanced-settings-20261002.json`。

## 重复验收

1. `swift build -c release --product greenbubbles-history`。
2. `python3 scripts/package-presentation-preview.py --polish`；用原生 UI 打开 `.local-install/GreenBubbles Polish Preview.app`。现有端到端流程经合成 CLI 驱动生产 model，输出 `Contents/Resources/offline-fixture/acceptance.json` 与 `presentation.png`。
3. 在预览检查欢迎/连接入口、会话分类及搜索、气泡层次和图像对齐。只归档合成图或脱敏结论。
4. 按 `LOCAL_SIGNING.md` 使用同一证书暂存应用更新，仅替换主界面程序，验证 helper 字节与 designated requirement 不变。
5. 原生退出安装版、安装、原生重开，确认不输入密钥自动连接，检查会话选择、搜索、时间分隔、附件，退出重开再复验。此步骤未通过时，不声明安装交付完成。

## 会话头像折叠栏

实时聊天左栏右上角新增折叠按钮。展开保持原生可调宽双栏；折叠宽度为 76 pt，仅显示顶部展开按钮和会话头像，隐藏标题、设置、分类、搜索及消息摘要。头像居中，保留选中背景，悬停名称和辅助功能名称，仍可点击切换会话和右键分类。折叠不清空筛选或分类、不改变当前会话及消息加载，列表继续分页。空列表提供图标提示；读取失败保留重试入口。

`historyConversationSidebarCollapsed` 仅保存布尔布局偏好，默认展开，重启恢复。需要调整分类、搜索、时间范围时先展开。导入记录的三栏导航不受此布局偏好影响。

重复原生验收：
1. 完整退出已安装应用，从原生 UI 重开，确认自动连接且不输入密钥。
2. 点击折叠按钮，确认窄栏只有头像和展开按钮，聊天区域变宽，当前聊天保持。
3. 在窄栏点击另一头像，确认消息区域切换，滚动列表仍正常。
4. 展开后确认分类、搜索、摘要和设置恢复；带筛选再折叠和展开，筛选保留。
5. 折叠后退出重开，确认自动连接及头像栏状态恢复，再展开检查正常。
6. 只归档脱敏检查结果，不提交真实聊天截图、联系人或正文。

## 会话右键菜单定位

会话行使用 `HistoryConversationContextMenu` 的 AppKit `NSMenu`，直接传入原始鼠标事件定位。避免 SwiftUI List 行 `.contextMenu` 引发焦点/滚动定位后，菜单与点击行分离。只拦截右键和 Control-左键；普通左键及滚动透传。菜单打开时快照动作，保留移到其他、移回个人/群聊、恢复自动分类。

重复原生 E2E：
1. 按 `LOCAL_SIGNING.md` 更新并完整退出重开，确认无需密钥恢复连接。
2. 在列表中段、滚动后和底部右键未选中行，检查菜单在点击位置附近、列表不跳动；Esc 关闭后仍在原位置。
3. 普通左键选择另一会话，确认聊天切换。Control-左键确认相同菜单。
4. 在离线合成预览中执行移到其他、移回及恢复自动分类，检查目标会话和分类；真实数据仅打开/取消菜单。
5. 折叠侧栏后重复打开/取消和普通选择，再展开复查。
6. 记录脱敏结论；系统安全确认未完成时将安装版验收记为 BLOCKED，不以合成验证替代。
