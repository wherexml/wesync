# GreenBubbles 原生桌面设计系统

## 方向

保留 SwiftUI / AppKit 与 macOS 14 支持。参考 ChunUI 的灰阶层次、单一品牌色、连续圆角和轻微按钮质感；不引入其 iOS 包、UIKit 呈现层或手机尺寸。实现为原创桌面样式，不复制上游源码。

参考：https://github.com/liseami/ChunUI

## 组件边界

- `HistoryDesign.swift`：语义背景、品牌绿、选中态、边框、12 pt 气泡圆角；`HistoryActionStyle` 只显式用于操作按钮，提供按压和禁用反馈。
- `HistoryChatPalette.swift`：聊天区、收发气泡和文字对比度以 `DARK_MODE.md` 为准，不在设计层重复定义。
- 实时浏览保持双栏，导入浏览保留原生分栏；搜索保留 NSSearchField 的输入法协调，分类保留系统 segmented picker，列表和菜单保留原生键盘交互。
- 欢迎页采用 28 pt 标题；实时聊天两栏标题统一使用 `HistoryDesign.title` 的 18 pt semibold。正文及列表保留桌面密度，不套用手机三档字号。
- 轻阴影只用于按钮，不在长消息列表加入持续动画。保留橙色警告和红色错误语义。
- 图片消息保持透明背景、原有缩略图尺寸与同侧对齐；不变更分页、缓存、连接与凭据处理。
- 聊天栏右上角保留折叠图标及 32 × 32 pt 的齿轮“高级设置”按钮，直接打开连接设置，使用悬浮提示和辅助功能名称，不叠加下拉箭头。旧菜单的全局搜索、返回聊天、来源信息和忘记连接入口移除；会话筛选、聊天内搜索及搜索结果页返回按钮保留，忘记连接只在设置中操作。
- 高级设置最上方增加“AI 读取黑名单”，个人/群聊/已选三栏、多选复选框、真实名称与侧栏同源头像、原生搜索，取消不保存；保存立即生效，详见 `AI_READ_BLACKLIST.md`。
- 高级设置“会话显示”使用原生 Picker：联系人和群聊时间范围，五档选项，立即生效并保存；详见 `CONVERSATION_RANGE.md`。
- 会话搜索使用 32 pt 高、9 pt 圆角、轻边框的 `HistorySearchField`，保留 AppKit 原生输入法、清空按钮及实时筛选；详见 `SEARCH.md`。
- 消息搜索默认折叠为刷新左侧的 32 × 32 pt 搜索图标，点击后仅在图标左侧展开输入框，不另占常驻搜索行；回车提交，Esc 或再次点击图标收起。

## 高级设置入口验收

原生退出并重开安装版，确认无需输入密钥即恢复聊天列表；右上角应仅显示一个齿轮，无菜单箭头。点击“高级设置”应直接打开连接设置，取消后保持会话列表可用，再退出重开复验。不要点击“忘记已保存的连接”或提交新凭据。脱敏结果见 `acceptance/advanced-settings-20261002.json`。

## 重复验收

1. `swift build -c release --product greenbubbles-history`。
2. `python3 scripts/package-presentation-preview.py --polish --identity EXISTING_APPLE_DEVELOPMENT_SHA1`；沿用 `LOCAL_SIGNING.md` 的现有证书，禁止临时签名。用原生 UI 打开 `.local-install/GreenBubbles Polish Preview.app`。现有端到端流程经合成 CLI 驱动生产 model，输出 `Contents/Resources/offline-fixture/acceptance.json` 与 `presentation.png`。旧临时签名预览可能遗留自己的测试钥匙串条目，不反复启动或要求用户输密码；这不代表正式应用需要迁移连接权限。
3. 在预览检查欢迎/连接入口、会话分类及搜索、气泡层次和图像对齐。只归档合成图或脱敏结论。
4. 按 `LOCAL_SIGNING.md` 使用同一证书暂存应用更新，仅替换主界面程序，验证 helper 字节与 designated requirement 不变。
5. 原生退出安装版、安装、原生重开，确认不输入密钥自动连接，检查会话选择、搜索、时间分隔、附件，退出重开再复验。此步骤未通过时，不声明安装交付完成。

## 会话头像折叠栏

实时聊天左栏右上角新增折叠按钮。展开保持原生可调宽双栏；折叠宽度为 76 pt，仅显示顶部展开按钮和会话头像，隐藏标题、设置、分类、搜索及消息摘要。头像居中，保留选中背景，悬停名称和辅助功能名称，仍可点击切换会话和右键分类。折叠不清空筛选或分类、不改变当前会话及消息加载，列表继续分页。空列表提供图标提示；读取失败保留重试入口。

`historyConversationSidebarCollapsed` 仅保存布尔布局偏好，默认展开，重启恢复。需要调整分类、搜索、时间范围时先展开。导入记录的三栏导航不受此布局偏好影响。

重复原生验收：
1. 完整退出已安装应用，从原生 UI 重开，确认自动连接且不输入密钥。
2. 点击折叠按钮，确认窄栏只有头像和展开按钮，聊天区域变宽，当前聊天保持。
3. 在窄栏点击另一头像，确认消息区域切换，滚动列表仍正常。
4. 展开后确认分类、搜索、摘要和设置恢复；带筛选再折叠和展开，筛选保留。
5. 折叠后退出重开，确认自动连接及头像栏状态恢复，再展开检查正常。
6. 只归档脱敏检查结果，不提交真实聊天截图、联系人或正文。

## 会话右键菜单定位

会话行使用 `HistoryConversationContextMenu` 的 AppKit `NSMenu`，直接传入原始鼠标事件定位。避免 SwiftUI List 行 `.contextMenu` 引发焦点/滚动定位后，菜单与点击行分离。只拦截右键和 Control-左键；普通左键及滚动透传。菜单打开时快照动作，保留移到其他、移回个人/群聊、恢复自动分类。

重复原生 E2E：
1. 按 `LOCAL_SIGNING.md` 更新并完整退出重开，确认无需密钥恢复连接。
2. 在列表中段、滚动后和底部右键未选中行，检查菜单在点击位置附近、列表不跳动；Esc 关闭后仍在原位置。
3. 普通左键选择另一会话，确认聊天切换。Control-左键确认相同菜单。
4. 在离线合成预览中执行移到其他、移回及恢复自动分类，检查目标会话和分类；真实数据仅打开/取消菜单。
5. 折叠侧栏后重复打开/取消和普通选择，再展开复查。
6. 记录脱敏结论；系统安全确认未完成时将安装版验收记为 BLOCKED，不以合成验证替代。

2026-10-03 修复记录见 `acceptance/context-menu-20261003.json`。菜单操作的合成验证通过；安装版自动重连和完整视觉定位仍待系统钥匙串确认后复验。

## 欢迎页操作说明（2026-10-03）

主操作使用可用的 `externaldrive` 系统图标，标签保持固有宽度，避免图标缺失或文字压缩。保留绿色主按钮的明暗配色及原生焦点环。移除底部三项承诺与拖入说明两行文字，文件夹拖入功能继续可用。

## 高级设置紧凑布局（2026-10-16）

弹窗宽 680 pt，高度固定 560 pt。标题与底部按钮固定，原生 grouped Form 内部滚动。黑名单、会话显示保持在前；读取工具、来源、凭据与记住/忘记连接归入“连接设置”折叠组。已连接默认折叠，首次连接默认展开。已连接时展开仍为只读查看，主按钮为“完成”，仅关闭窗口；点击“修改连接”后才显示可编辑字段及“重新连接”，首次连接保留“连接并查看”及原校验流程。会话范围立即保存，黑名单通过选择器独立保存，关闭设置不回滚这两项。

复验：完整退出安装版并原生重开，确认无需输入密钥自动连接；打开高级设置，检查常用两组及已连接状态、无路径暴露；展开连接配置并滚动到底，检查凭据分支、记住/忘记入口与固定底部按钮；折叠后点击完成，聊天保持；重新打开黑名单选择器并取消，不修改策略；再次退出重开并重复检查。只记录脱敏结果。

## 主聊天与设置细节（2026-10-17，覆盖上方尺寸及布局）

主聊天侧栏顶部仅显示 WeSync 标题，两栏工具区均为 56 pt 高；齿轮、折叠、搜索和刷新复用 `HistoryIconButtonStyle`，32 pt 点击区、15 pt SF Symbol、8 pt 圆角悬停底及按压反馈。搜索展开时使用品牌选中态，仍只在搜索按钮左侧显示原生 NSSearchField。会话行复用 `HistoryConversationRowStyle`：10 pt 内缩圆角底、13 pt 名称、12 pt 单行摘要、10 pt 等宽数字时间，隐藏原生行分隔线。保留原始事件右键菜单、分页、分类和 76 pt 折叠栏。

高级设置为 680 × 520 pt，固定标题和底部操作，内容使用 ScrollView 与 `HistorySettingsGroup`，14 pt 圆角、明确浅灰/深灰分组底及细边线。黑名单、会话显示、连接设置顺序不变；普通功能说明放入独立问号 popover，不常驻显示，错误和凭据警告仍按原有条件显示。时间范围使用右侧固有宽度的原生 Picker。已连接查看态底部只显示“完成”，Escape 可关闭；修改连接和首次连接保留“取消”与连接动作。帮助弹层先响应 Escape。连接仍默认折叠、展开只读，修改连接后才显示安全输入。

重复验收：运行现有离线 presentation E2E，核对合成原生主聊天、选中行、问号、Picker、连接展开/编辑与固定操作栏；同身份暂存、保留旧包、安装后两次原生冷启动自动重连，检查会话选择、搜索展开/收起、折叠、右键、刷新和高级设置。真实数据仅检查，不更换凭据或保存黑名单。原生截图仅保留合成数据，实机结果只记录脱敏结论。


## 连接配置字段与查看状态（2026-10-16）

已连接时展开配置默认只读，保留“完成”动作；不显示空白密钥输入框，显示当前连接已解锁。点击“修改连接”才进入编辑并显示“重新连接”。首次连接直接可编辑。路径字段采用显式上方标签、整行内容与固定宽度选择按钮，不让 grouped Form 自动把长路径右对齐；只读路径使用等宽字体、中间截断、可选择文本及完整路径悬停提示。凭据输入使用显式标签、占位提示和 roundedBorder 安全输入框，不回填或显示已有密钥。

“忘记已保存的连接”需原生确认；取消不移除连接。连接字段编辑沿用原有模型与校验，未提交时不替换当前运行连接。会话显示与黑名单仍独立保存。

重复验收：安装版原生退出重开，确认自动连接；打开设置并展开连接，确认只读路径、解锁状态及“完成”；点击完成后重新打开，点击“修改连接”，检查路径输入、来源选择与安全输入框的对齐及底部“重新连接”；不填凭据、不提交更换，取消回到聊天。打开忘记确认并取消，再次冷启动确认自动连接。只归档脱敏检查结果，见 `acceptance/connection-ui-20261016.json`。
