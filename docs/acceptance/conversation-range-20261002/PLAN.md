# 会话时间范围 E2E 计划

实现前列出失败路径：范围边界 off-by-one；自然月/年误用固定天数；毫秒时间被误判；无时间旧联系人混入；个人/群聊筛选不一致；搜索绕过范围；切换范围仍展示被隐藏聊天；重启丢失选择；过滤删除缓存或破坏分页；更新签名变化导致连接失效。

合成 native E2E 使用既有隔离预览和真实 CLI transport：固定参考时间，合成不同年龄的个人、群聊、其他会话及毫秒时间，逐项断言五档范围、包含边界、搜索交集、隐藏选择清空、扩大范围恢复、持久化及原缓存不变。输出 JSON，不新增单元测试。

安装验收：验证同一稳定签名及 helper 字节，原生退出、更新并重开，检查无需输入密钥自动连接；设置选择五档，检查个人/群聊列表与空结果；选择 1 个月后再退出重开，复验设置与自动连接。只归档脱敏计数和结论。
