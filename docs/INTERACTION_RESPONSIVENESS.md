# 菜单、点击响应与折叠栏

## 实施前失败场景

- 应用菜单缺少设置，折叠后齿轮也不可见；关闭或隐藏主窗口时菜单不能恢复设置。
- 关于窗口未前置，或未显示随安装包更新的版本和构建号。
- 76 pt 侧栏叠加原生 inset 列表缩进与按钮 padding，头像和选中背景向右偏移、被裁切。
- 每次分页、刷新及后台预热都在主线程打包全部缓存、编码 JSON、加密和写盘，阻塞点击。
- 异步缓存旧任务覆盖新任务、切换来源后错误污染当前页面、退出前末次缓存丢失。
- 改动破坏会话选择、分类筛选、右键、分页游标、加密格式或自动重连。
- 合成验收误访问真实凭据或聊天数据，安装更换证书或 helper 摘要。

## 验收契约

保留 SwiftUI/AppKit。菜单提供“关于 we-sync”和“设置…”（⌘,），菜单栏图标同步提供入口。
折叠栏仍为 76 pt，头像、选中底与顶部按钮共用水平中心。
缓存快照在主线程仅复制值，压缩头像、JSON 编码、加密与原子写盘交给串行后台执行；同一缓存文件的最新任务优先，跨来源末次保存互不取消，退出等待所有末次保存。

使用独立合成预览验证缓存加密、保存顺序、重连与主线程心跳，并保留原生菜单/侧栏截图。
随后沿用安装版证书、保留全部 helper，原生退出、安装、两次冷启动，确认无凭据输入自动重连，检查菜单、设置、关于、折叠、选择、搜索与刷新。
截图只包含合成数据；安装版只记录脱敏结论。验收产物链接随实际完成情况补充。

## 重复步骤

1. 运行 `python3 scripts/local-ci.py`；23 项均须 PASS。
2. 使用现有 Apple Development 证书运行 `python3 scripts/package-presentation-preview.py --identity "$WESYNC_SIGNING_IDENTITY"`。预览 Bundle ID 必须为 `me.greenbubbles.PresentationPreview`，该命名空间的合成缓存使用固定公开测试材料，不访问生产钥匙串。
3. 退出预览；在其 `Contents/Resources/offline-fixture/` 内仅保留 `preload-acceptance` 场景标记，清除本场景旧 `requests.jsonl` 与结果文件，使用同一证书重新签名预览，再通过原生 UI 打开。等待 `preload-acceptance.json` 的 passed=true。应完成 100 个人 + 50 群聊 × 40 条的预热、150 次即时缓存切换、分页、错误恢复、加密缓存与恢复，共 316 项检查。
4. 原生退出预览，切换为 `message-cache-acceptance` 标记，清除旧请求与结果文件，同证书重新签名并原生打开。等待 `message-cache-acceptance.json` 的 17 项检查通过，覆盖目录补齐、连续游标、取消旧请求、刷新失败保留、损坏缓存恢复和重连。
5. 在预览折叠侧栏，确认 34 pt 头像、选中底与顶部按钮居中；展开后分类、搜索、选择仍保留。截图仅使用合成来源。检查 ⌘, 和齿轮打开同一设置页。
6. 按 `LOCAL_SIGNING.md` 使用 `stage-local-brand-update.py --main-executable .build/release/greenbubbles-history` 暂存同身份更新，保留全部 helper 字节；备份安装版后原生退出、安装并打开。两次冷启动均检查无密钥输入自动连接，打开聊天、刷新、设置、关于及折叠偏好。

心跳结果衡量整段合成流程的主线程最大调度间隔，包含批量选择和同步缓存恢复；它不是显示帧率或每次点击延迟，也没有同硬件基线对照。当前改动消除的是可定位的全量缓存持久化阻塞，不宣称所有操作达到固定帧率。

## 2026-11-11 结果

最终安装版为 0.10.0（65）。23 项本机检查、316 项预热与 17 项缓存 E2E 全部通过；同证书与完整 helper 字节保留。两次原生退出后重开均自动连接，无凭据输入或权限重置，聊天、刷新、设置、关于和折叠状态通过。首次候选包另完成搜索 Escape、侧栏展开/折叠与右键取消的原生检查。
