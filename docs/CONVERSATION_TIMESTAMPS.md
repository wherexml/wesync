# 会话列表时间

实时记录与导入记录的会话列表右上角共用 `HistoryConversationTimestamp`。

- 今天：24 小时制 `HH:mm`，如 `17:31`。
- 昨天：`昨天 HH:mm`，如 `昨天 21:17`。
- 前天及更早：补零公历日期 `MM/dd`，如 `09/30`，不显示英文月份。
- 以本机时区和日历日判断，不按过去 24/48 小时判断；每分钟更新，跨午夜无需重新加载记录。
- 无最后消息时间时不显示时间；时间标签保留完整宽度。

原生验收：以同一稳定证书更新安装版，退出后重开，确认无需输入密钥自动连接；在会话列表验证今天、昨天、更早三类标签。只记录脱敏时间和验证结论，不保存联系人或聊天内容。
