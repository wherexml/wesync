# 中文界面

用户要求：欢迎页及其后续页面使用易懂中文，包括按钮、表单、选项、说明、错误提示与文件选择窗口。

范围：欢迎页；连接本机记录/加密备份的全部方式；创建备份的设置、恢复词确认、进度、成功/失败页面；导出记录选择与加载；概览、联系人、搜索、记录完整程度；附件验证与 PDF 预览。底层协议、存储键、真实文件名/路径、聊天原文及恢复词本身保持原值。

术语：snapshot → 加密备份；CLI → 本机读取工具；recovery kit → 恢复词文件；bounded query → 按需加载。生产错误经过中文展示映射，避免直接显示内部英文错误。未知读取限制用中文提示结果可能不完整，不宣称成功。

验收前检查：三条欢迎页路径均可打开/取消；连接方式逐一选择；缺失凭据显示中文错误；备份可选设置、确认、进度与结果文案完整；文件选择窗口中文；长中文布局不截断；原始数据和协议常量不变；正式安装保留签名权限约束。

预览打包时声明简体中文为支持语言，SwiftUI 根视图使用中文区域。正式安装包也须保留 Info.plist 的 CFBundleDevelopmentRegion=zh_CN、CFBundleLocalizations=[zh_CN]，以便系统自动菜单/文件选择器采用中文。原始文件名及恢复词不是界面文案，不翻译。
