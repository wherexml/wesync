# we-sync 产品首页

[线上首页](https://wesync-mac.pages.dev/) 沿用深色布局。首屏用缓慢移动的低亮度光晕衬托标题。顺序为全屏首屏、三步产品演示、逐字点亮、四屏横移、六张能力卡、隐私、FAQ 和底部下载入口。简中、繁中、英文从一份模板生成。

## 验收

- 首屏光晕随时间缓慢变化，标签页隐藏时暂停。演示滚动进入后播放「连接 → 搜索 → AI 分析」，可暂停、重播，也可通过标题直接选择步骤。
- 连接和搜索按原生应用的本机连接设置、消息搜索界面制作。用「上线」筛选样例消息，输入不存在的词查看空状态，再清空查看全部。
- AI 分析在 Codex 界面演示通过 `$we-search` 发出与同一会话有关的问题，画面停在已发出的提问。网页内的演示只使用合成数据和静态文案。
- 桌面功能区固定在视口内，随纵向滚动横移四屏并更新进度。手机和减少动态效果模式按顺序堆叠。
- 检查手机菜单、语言切换保留锚点、FAQ 展开和收起、源码与首次设置链接。
- 减少动态效果时保持首屏静止，三步可手动切换。无 JavaScript 时展示三个场景、默认搜索结果、FAQ 和各语言链接。预览只加载同源静态资源。
- 三种语言都使用「让你的 AI 轻松读取聊天记录」的产品定位。下载按钮直达相同版本的 GitHub Release DMG。只在该文件公开可匿名下载、字节摘要已核对后部署新版首页。

## 构建和部署

```sh
python3 scripts/build-website.py
python3 -m http.server 38133 --bind 127.0.0.1 --directory .build/website
```

在 `http://127.0.0.1:38133/` 复验。构建同时输出 `.build/website.zip`，只包含三个语言页面、静态资源和 `_headers`。在 Cloudflare Pages 项目 `wesync-mac` 中创建生产部署并上传 ZIP。线上复验时保存桌面、手机和滚动场景截图，核对内容安全策略。
