# 图片消息对齐

缩略图按原图宽高比计算实际尺寸，边界为 300 × 240 pt。按钮、圆角与图片使用同一尺寸；不得用较宽的弹性容器居中放置竖图。接收图片左边缘与接收文字气泡左边缘一致，发送图片右边缘与发送气泡右边缘一致。

## 原生验收步骤

1. 使用原固定证书签署更新包，确认 designated requirement 相同、查询和发送工具字节未变。
2. 原生退出已安装应用，安装后通过原生界面重开；无需输入密钥即可自动显示会话。
3. 打开含竖图及相邻文字的个人会话，检查图片左侧与文字气泡左侧对齐；检查发送图片靠右。
4. 点击图片打开预览，再关闭，确认缩略图位置保持不变。

验收仅保存脱敏结果，不保存联系人、聊天正文或原始截图。
