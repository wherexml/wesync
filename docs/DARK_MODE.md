# 聊天明暗配色

## 实现前失败清单

- 暗黑模式浅绿发送气泡继承白字，正文及文件名无法阅读。
- 引用正文、引用发送者、附件说明各自覆盖文字样式，修正父视图仍可能留下白字。
- 左栏、列表、标题及时间线使用不同系统材质，出现无意的色块与背景层次反转。
- live 与 imported 使用不同气泡配色；切换系统外观后配色未同步。
- 图片缩略图背景或对齐被配色修改影响；重启更新后失去记住连接。

## 约定

统一 `HistoryChatPalette`：暗色会话栏 #242424、聊天区 #191919、接收气泡 #2C2C2C、发送气泡 #38B375，发送正文 #102018。亮色沿用浅绿发送气泡 #D4F0C4，接收白底，左右背景为浅灰。
发送气泡内部使用浅色文字语义，正文、引用、附件说明保持深色；不改变窗口或全局外观。系统消息、时间分隔与头像外部标签仍遵循窗口外观。图片保持透明背景、原尺寸及对齐。

## 可重复验收

1. `python3 scripts/package-presentation-preview.py --dark-mode --identity EXISTING_APPLE_DEVELOPMENT_SHA1`，原生打开隔离预览，运行现有合成端到端流程；输出 acceptance.json、presentation.png 及 light/dark 两张原生渲染图。
2. 检查两种外观的发送文字、引用、文件卡片、接收文字和左右背景；预览仅使用合成数据。
3. release 编译，保持安装应用固定证书身份及全部 helper 字节；原生退出后安装，再原生打开。
4. 确认无需数据库密钥自动连接；打开已有会话检查收发气泡与背景，退出重开再确认。
5. 仅提交脱敏验收记录及合成图，不提交真实消息截图。
